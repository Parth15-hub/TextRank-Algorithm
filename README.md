# TextRank Algorithm

A Node.js + Express web app for extractive text summarization using TextRank and related similarity/ROUGE/BERT-style routes.

## Run locally

```bash
npm install
npm start
```

Open: http://localhost:3000

## Deploy on Render

- Build Command: `npm install`
- Start Command: `npm start`
- Node version: Render default Node 20+ is fine

The server uses `process.env.PORT || 3000`, so it works on Render.
